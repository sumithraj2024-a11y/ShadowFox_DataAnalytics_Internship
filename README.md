# ShadowFox Data Analytics Internship

## Data Analytics Projects – Beginner & Intermediate Levels

This repository contains my work completed as part of the **ShadowFox Data Analytics Internship**.

The projects demonstrate practical experience in **data cleaning, data analysis, data visualization, business insights, and reporting** using Microsoft Excel and Python.

## Internship Levels Completed

### Level 1 – Beginner

**Project:** Sample Superstore – Sales & Profit Analysis

**Tools:** Microsoft Excel, PivotTables, Charts, and Dashboard

Key areas covered:

- Data exploration and cleaning
- Sales and profit analysis
- Regional analysis
- Category analysis
- Customer segment analysis
- Shipping mode analysis
- Excel dashboard creation
- Business insights and recommendations

**Project Folder:** `level_1/`

### Level 2 – Intermediate

**Project:** Online Retail II – Customer, Revenue & Business Performance Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib, and Jupyter Notebook

Key areas covered:

- Data loading and exploration
- Data cleaning and preparation
- Revenue analysis
- Customer behaviour analysis
- Product performance analysis
- Monthly revenue and return trends
- Geographic revenue analysis
- Customer segmentation
- Data visualization
- Business insights and recommendations

**Project Folder:** `level_2/`
