# Dataset Information

## Online Retail II Dataset

The **Online Retail II** dataset contains transactional records from an online retail business covering the period from **December 2009 to December 2011**.

### Source

**Kaggle – Online Retail II Dataset**

The dataset contains two yearly sheets:

- Year 2009–2010
- Year 2010–2011

It includes transaction details such as invoice numbers, products, quantities, prices, dates, customer IDs, and countries.

### Used For

This dataset was used for:

- Revenue analysis
- Customer behaviour analysis
- Product performance analysis
- Sales and return trend analysis
- Geographic analysis
- Business insights and recommendations

### Dataset Access

The original Excel dataset is not included in this GitHub repository because of its large file size.

Please download the **Online Retail II** dataset from Kaggle and place the downloaded Excel file inside this `dataset` folder before running the notebook.

**Note:** The dataset is used only for analysis and learning purposes as part of the ShadowFox Data Analytics Internship.
